# Air Rhythm

An osu!-style rhythm game played with your hand in front of a webcam. Aim with the
point between your thumb and index finger, and **pinch** to hit circles on the beat.

## Play it (Windows, no Python needed)

1. Download `AirRhythm-<version>-windows-x64.zip` from the
   [Releases page](https://github.com/bashirmouri/air_rhythm/releases).
2. Unzip it anywhere and run `AirRhythm\AirRhythm.exe`.

The first start takes a few seconds longer; later starts take about a second.
Windows may show a SmartScreen warning because the game isn't code-signed: click
*More info* → *Run anyway*. Everything the game needs is in the zip, so it works offline.

**To update:** download the new zip and replace the old folder. Your settings and
calibration are kept (see [Where files are saved](#where-files-are-saved)).

**First start:** a short setup guide checks your camera and light, lets you try a pinch on
three circles, and measures your input delay (webcams add 50-150 ms; the game subtracts it
from every hit). You can skip it, and run it again any time from **Settings** > *Setup guide*.
Playing on **Bluetooth headphones**? Set *Sound delay* in Settings first (they play sound
~150-250 ms late), then *Measure input delay*.

**Settings** also has the volumes, which camera to use, the size of the hand area (smaller =
less arm movement), how loose a pinch can be, cursor smoothing, fullscreen and an FPS counter.
The camera view there is large, so you can try changes on the spot. Changes apply right away
and are saved when you close the game.

## Controls

| Key | Action |
|---|---|
| Pinch / click / Z / X | Hit, or press a menu button |
| Enter | Play |
| L | Switch level: Easy / Normal |
| S | Settings |
| C | Measure input delay (calibrate) |
| I | Switch hand / mouse input |
| N | No-fail on/off |
| M | Menu music on/off |
| V | Show/hide camera view |
| F11 | Fullscreen |
| Esc | Pause during a song (Esc again resumes); back / quit elsewhere |
| R / Q | When paused: retry / quit to menu |

*First Steps* comes in two levels: **Easy** (60 circles, never faster than one per second,
bigger circles, looser timing) and **Normal** (128 circles that follow the melody).

**Tracking tips:** a bright, even light on your hand makes tracking far more stable. Keep your
hand inside the white box in the camera view (press **V** to show it). The game tells you when
something is likely to hurt tracking: a dark room, a slow camera, or a hand that keeps getting
lost. Look for the orange line at the top of the screen (or in the menu's top-right corner).

## Where files are saved

Settings, the generated songs and beatmaps, the hand model and the log live in a per-user folder,
not next to the game:

| OS | Folder |
|---|---|
| Windows | `%LOCALAPPDATA%\AirRhythm` |
| macOS | `~/Library/Application Support/AirRhythm` |
| Linux | `~/.local/share/air-rhythm` (or `$XDG_DATA_HOME/air-rhythm`) |

**Portable mode** keeps everything next to the game instead: put an empty file named
`portable.txt` next to `AirRhythm.exe` (or start with `--portable`).

Damaged files fix themselves: a half-written song or beatmap is regenerated on the next start,
and a broken hand model is replaced.

**Problems?** The log `air_rhythm.log` in that folder records what happened. If the game hits an
unexpected error it shows where the log is (press **L** in the error window to open the folder).
Please attach it when you report a bug.

## For developers

Needs Python 3.12–3.15 (tested on Windows, Linux and macOS for each).

```bash
python -m venv .venv
.venv\Scripts\activate                 # macOS/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt    # exact, tested versions
pip install -e .                       # the game itself, as an editable package

python -m air_rhythm                   # play (--mouse, --autoplay, --portable)
python -m pytest                       # all tests, ~2 min, no camera/window/sound/internet
python -m ruff check .                 # code checks
```
